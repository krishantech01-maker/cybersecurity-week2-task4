# Introduction to Cryptography: Encryption and Hashing

## Project Overview
This repository contains structural academic assets covering core cryptographic paradigms. It includes a comprehensive report on data security principles, a structured markdown presentation comparing key exchange mechanisms, and a functional Python implementation showcasing cryptographic hashing.

## Directory Structure
- `presentation.md`: Markdown presentation comparing Symmetric vs Asymmetric cryptographic systems.
- `docs/cryptography_basics.md`: In-depth report covering data hashing and cryptographic models.
- `src/crypto_demo.py`: Python script illustrating SHA-256 integrity verification.
